# Fonts served from the repository

Variable WOFF2 files (latin / thai subsets) from the Fontsource npm packages
`@fontsource-variable/*` (geist 5.3.0, geist-mono 5.3.0, noto-sans-thai 5.3.0,
fraunces 5.3.0, source-sans-3 5.3.1). All five are SIL Open Font License 1.1;
each licence text is beside the files as `LICENSE-<family>.txt`.
Loaded by `src/app/layout.tsx` with `next/font/local`, so a build needs no network.
