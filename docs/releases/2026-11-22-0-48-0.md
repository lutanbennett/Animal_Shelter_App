## This is the first release in sixteen days that MAILS, and that is most of what it is for

**He asked for it in those words:** *"lets do a major release, email to be sent and note any gaps in
test"*. The email was the question put to him, never "major or minor" — those two words have meant
different things to the two sides of that conversation — so `major: true` and the middle-number bump
`0.47.10 → 0.48.0` were both **derived from his answer and then asserted**, not inferred:

```
ok   mail PRESENCE: majorReleasesSince(previous) is exactly the new version  [["0.48.0"]]
ok   control: from further back, an older major release is still found  [0.47.0 in ["0.48.0","0.47.0"]]
```

**One standing fact goes with it, stated rather than re-asked: a major release currently mails one
person — Lutan.** The shelter's own address is not on the production admin list and
`lannacareforanimals@gmail.com` is expected to be skipped by the relay with `E_RECIPIENT_NOT_ALLOWED`.
"Mails every admin" overstates the lever, and he already knows it; it is written here so this record does
not imply a wider audience than the mail has.

### So this release is the proof `#w4k9n` (e) has been waiting for

**no release has mailed since**, so the fix sat unproven for sixteen days. MAILRESULT

It adds one column: `staged boolean not null default false` on `shelter_drive_credentials`. It lets a
shelter that **already** has a Drive connect its own Google account without every stored Drive id going

and the shelter keeps working.

**The code that reads it is not in this release, and that was read rather than assumed:**

- `git grep "staged" origin/main -- src/lib/google/` returns **nothing**.

today's behaviour, tightens no constraint, rewrites no row, and grants nothing to `anon` or
