## What shipped

Nine notes. A delivery bill can now hold several items instead of one, with the bill total typed once, a running total shown against it, and a *Something else* choice for what is on no list — kept on the bill, changing no stock count. Utility bills get a page of their own, recorded against the month each bill covers and listed month by month, and a photo in the Bills inbox can be filed as one. Bills settings arrive beside them: the places the shelter pays bills for, the accounts at suppliers and the kinds of bill, with each inbox card now asking what it is for. A failed video upload says **where** it stopped instead of giving one message for four causes. The Donate, Foster, Volunteer and About pages show a poodle drawing when no photo has been chosen. A wrong intake date can be corrected on a resident who has died, under the card that already existed. The resident page says so when a `#` tag link in the intake note could not be saved, instead of saving the note and dropping the link silently. A clinic visit's details page opens for anyone who can view medical records. And release notes can be written for Admin only.

## The code-identity check fired on repo tooling, and that is worth reading carefully

`main` moved twice after the cut merged: **#1254** (backlog item ids, and the backlog page generator moving into the repo) and a `backlog` branch merge. The post-merge hook pulled them into the main checkout, so the test Worker deploy — which takes no `--ref` — built from `cd2b0070` rather than the release commit.

**The runbook's check is `git diff --name-only <a>..<b> | grep -vE '^(docs/|\.claude/)'`, and it is NOT empty.** It names eight files:

```
.githooks/pre-commit
.github/workflows/ci.yml
README.md
scripts/backlog-ids.mjs
scripts/check-backlog-ids.mjs
scripts/gen-backlog.mjs
scripts/lib/backlog-page/head.html
scripts/lib/backlog-page/priorities.html
```

**The runbook says any line means stop. It was read rather than obeyed mechanically, and the conclusion is that nothing served differs**: a git hook, a CI workflow, the README, three backlog tools and two HTML templates for the backlog artifact page. A second grep confirmed it — **not one file is in `src/`, `worker/`, `public/`, `next.config` or `package*`**, so nothing `next build` includes changed, and nothing reaches either Worker bundle or either Pi build.

**Nothing was rebuilt**, because the trap is explicit that `main` moving does not license chasing a SHA, and a past release poisoned the Cloudflare cache doing exactly that.

**The honest residue, stated rather than smoothed over:** the check's exclusion list (`docs/`, `.claude/`) does not cover `scripts/`, `.github/` or `.githooks/`, so a change that is documentation-shaped in every sense that matters still trips it, and a release manager who follows the instruction literally would stop a sound release. **Widening the pattern — or having it name which of its hits are actually built — is a backlog item, not a release-time change.** Filed under *Architecture*.
