# Appeals became Campaigns, Desexing became Sterilisation (2026-11-04)

Lutan, 2026-11-04: *"please change Appeals to Campaigns and Desexing to Sterilisation in the system"*. Backlog `#2dj7q`.

## What changed
- **Words a person reads**, English: `src/lib/i18n/dictionaries/en.ts` (93 strings, including the permission and card descriptions on Who does what, the donation form, the resident adoption profile "Sterilised (spayed / neutered)") and `src/lib/manual/en.ts` (25 strings). The change was made by a string-literal-only script, so comments, keys and table or column names were not touched. Two strings sitting before a `:` in a ternary were missed by it and fixed by hand.
- **Thai** (`th.ts`): "การระดมทุน" in the appeals blocks, nav, cards and donation form became "แคมเปญ" (and "การรณรงค์ระดมทุน" became "แคมเปญระดมทุน"). Thai for sterilisation was already "ทำหมัน", the everyday word, so it stays. **Unreviewed Thai**, written by Claude.
- **Addresses**: `/appeals` → `/campaigns`, `/management/appeals` → `/management/campaigns`, `/management/desexing-drives` → `/management/sterilisation-drives`, `/services/desexing` → `/services/sterilisation`, with the `src/app/` folders moved to match. Updated: `public-paths.ts` (both lists), `public-pages.ts`, `sitemap.ts`, `routes.ts`, `write-requests.ts`, the permission-catalogue, phone-width and public-path check scripts.
- **Redirects** (`next.config.ts`, permanent): `/appeals`, `/appeals/:id`, `/services/desexing`. The staff addresses have none (nothing outside the app links to them).
- **Card `run_fundraising_events`** now opens `/management/campaigns` (it was a placeholder pointing at the appeals page, which no longer exists at that address). It is still a placeholder until the events screen exists (`#2zi2j`).
- Release note added to `unreleased`; the unreleased Who-does-what note was reworded to say "sterilisation". Published release notes untouched.

## What deliberately did not change
Identifiers: `src/lib/appeals/`, `src/lib/desexing/`, the i18n object keys (`t.appeals`, `t.desexing`, `t.nav.desexingDrives`), database tables and columns (`appeals`, `desexing_drives`, `is_desexed`, `designation = 'appeal'`), card keys (`appeal.run`, `appeal.medical_photo`, `run_appeals`), the manual topic ids (`running-an-appeal`, `desexing-drives`, which are anchors), and the hideable-page keys `page:appeals` and `page:desexing` (named in check constraints `0256`/`0290` and in rows an admin has set). The Worker has no path list of its own: it imports `public-paths.ts`.

Not touched: `docs/` pages (`features.md`, `card-walkthrough.md`, `roles-and-permissions.md`) are developer documents, and `docs/card-walkthrough.md` is regenerated by `scripts/gen-card-walkthrough.mjs`, which was updated to the new address.
