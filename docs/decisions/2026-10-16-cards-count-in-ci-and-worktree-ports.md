# 2026-10-16 — The twenty-one-card count runs in CI; worktree.mjs never issues a port twice

**Card count.** `check-cards-schema.mjs` needs the dev token, so CI could not run it, and the harness had been crashing unnoticed (see `2026-10-16-check-harness-crashes.md`). Its first assertion reads only `cards.ts` and `catalogue.ts`, so `scripts/check-cards-count.mjs` repeats it with no database: exactly 21 cards, every bundle entry names a catalogue activity, every `includes` names a card. `check-cards-schema.mjs` is untouched and keeps its own copy of the assertion, so nothing was loosened; the cost is ~20 duplicated lines (the resolver hook), accepted over editing a strict script. New `cards-count` job in `ci.yml`, **no `continue-on-error`**: it fails honestly. "Advisory" means only that it is not a required check in branch protection, which is Lutan's call. Neither audit workflow was touched. Shown to work: with a deliberately broken `cards.ts` the script exits 1; unmodified it prints the ok line and exits 0.

**Ports.** `worktrees()` hides the desktop app's spare checkouts under `.claude/worktrees/` so they are never listed or cleaned, and `nextFreePort` took that filtered list, so it could not see them. It now asks for the unfiltered list (`worktrees({ includeSpare: true })`) and counts every `.port` git knows about. Part (b): `writeLaunch` used `readPort(dir) ?? MAIN_PORT`; for any worktree other than the main checkout with no `.port` it now allocates one, writes `.port`, and aims `launch.json` at it, so a session can no longer attach to the main checkout's or another stream's server on 3000. `cmdDev` reads the port after `writeLaunch` for the same reason.

**Not done.** `worktree.mjs list` still does not show spare checkouts, and `done` cannot remove them (`git worktree remove` does). Optional in the item and not cheap enough here. A port is allocated from `.port` files only; a server running on a number no `.port` claims is not detected.

**Shown to work.** A throwaway detached worktree with no `.port`: `launch` assigned 3010 (free), wrote `.port` and `launch.json` on 3010, and a second run kept 3010. The throwaway was removed. `list` still renders every row and port for the main checkout and streams.
